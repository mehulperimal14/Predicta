Segment A

SCADA / PLC File Analysis

Plant engineers upload what their PLC, SCADA, DCS or historian already recorded (CSV, XLSX, XLS). Predicta re-evaluates the whole history against nine failure signatures and explains which causes could have led – or are leading – to damage, with evidence and an inspection checklist. No new sensors needed.

Upload file → quality score → map tags → 5-layer risk → change-points → trend forecast → 9 fault signatures

Segment B

Live IoT Monitoring

ESP32 or other microcontrollers stream sensor readings continuously to the cloud. Predicta re-evaluates every device on a rolling window and tells you whether it is healthy, which way each variable is trending, and roughly how long until it reaches a breakdown limit if nothing changes.

ESP32 → HTTPS (device key) → rolling window → rules + anomalies → trend forecast → status & live alerts
